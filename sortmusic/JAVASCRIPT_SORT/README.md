- How to get them (about 2 minutes)

Go to developer.spotify.com/dashboard and log in with any Spotify account (a free account works).
Click Create app.
Fill in any name and description (e.g. "Emby popularity").
For Redirect URI, enter http://127.0.0.1:8888/callback. The form requires one, but this page doesn't use it.
Tick the Web API option, accept the terms, and save.
Open the app's Settings. Copy the Client ID, then click View client secret and copy that too.
